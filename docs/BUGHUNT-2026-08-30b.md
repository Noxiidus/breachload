## Bugs found & fixed

### 1. Kerberoast TGS user regex truncated machine-account names
**Where:** `analysis/kerberos._TGS_USER_RE`.
**Symptom:** the hashcat TGS format is `$krb5tgs$23$*user$realm$spn*$...`. Machine
accounts end in `$` (e.g. `WEB01$`), so a simple `[^$*]+\$` stop stripped the trailing
`$` and mis-attributed the hash to `WEB01`. The user column on the credential is used
by lateral-movement suggestions — a computer credential mis-labeled as a normal user
could route into the wrong reuse attempts.
**Fix:** the regex now stops at `$` followed by an *uppercase letter/digit* (i.e. the
start of the realm), so `WEB01$` survives intact. Regression:
`test_machine_account_tgs_user_intact`.

  store space-bearing passwords in the Winlogon `DefaultPassword` REG_SZ.

## Bugs found & fixed

### 1. Upload-bypass ladder contained a literal NUL byte in a filename
**Where:** `analysis/webrce_ladders.UPLOAD_EXTENSION_LADDER`.
**Symptom:** the ladder listed ``"shell.php\x00.jpg"`` for the legacy PHP null-byte
trick. But subprocess argv on POSIX rejects embedded NULs (`ValueError: embedded
null character`), so calling any `uploadfuzz` argv containing that filename would
crash the run instead of firing the probe. Verified: `subprocess.run(['/bin/true',
'shell.php\\x00.jpg'])` raises immediately.
**Fix:** replaced with `"shell.php%20.jpg"` (percent-encoded space bypass, argv-
safe). The already-present `"shell.php%00.jpg"` still covers the URL-encoded null
trick, which is the one that actually works over HTTP anyway.

## Reviewed OK (no change needed)

- **secretscan** — placeholder filter cuts obvious noise ("changeme", "your..."),
  every hit becomes confirmed + typed Credential; DB-URI/JWT/private-key patterns
  survive fuzz with no false crashes.
- **unauth_api** — probe/parse robust to empty and None input; Docker `/version`
  marker (`"ApiVersion":...,"Os"`) specific enough that Portainer's `{"Version":...}`
  does not false-match.
- **defaultcreds** — `svc.name=None` handled (`(svc.name or "").lower()`), the mysql
  blank-password token is dropped by the `""`-filter, sshpass argv accepts an empty
  password intentionally.
- **app_secrets** — decoders guarded behind `try/except`; padding fixup on GPP
  cpassword; `_PROFILES` covers 15 apps with distinct schemes; `decrypt_nifi`
  round-trip in tests.
- **writable_root_paths** — empty/None input returns `[]`; `_blocks` splitter is
  the single point of truth.
- **privesc_classes** — PATH-hijack conservative (only flags when a writable dir
  is in PATH); writable-service-unit and writable-SUID cases both scoped to actual
  root-referenced targets.
- **ssrf_imds** — AWS/GCP/Azure token regexes match on their real formats; empty
  and non-JSON bodies return `([], [])`.
- **winprivesc_classes** — GPP cpassword finding is always emitted (confirmed only
  when we actually decrypt); scheduled-task/service-ACL detectors need explicit
  writable-set or accesschk-output tokens.
- **deserialization** — payload_commands never runs anything; every argv ends with
  the command; per-language deduplication holds.
- **nuclei** — new CVSS/proof fields are optional-safe; classification.cvss-score
  parsed with try/except; existing 25 nuclei tests all pass.
- **ADCS auto-loop** — scope-checked, template extracted from finding title,
  falls back to "User" template; no-op when preconditions miss.
- **MCP server** — tool errors reported as `isError: true` content (never
  raise); `params or {}` guards; unknown method returns -32601.
